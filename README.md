# linux-cli-survival-lab
Hands-on Linux CLI and system administration lab for building Linux and cybersecurity fundamentals.


# Lab Praktik Mandiri CLI & Administrasi Sistem Linux


## Tentang
Repository ini berisi catatan praktik langsung (hands-on) saya dalam mempelajari operasi command-line Linux dan dasar-dasar administrasi sistem.

Project ini berfokus pada pemahaman Linux melalui latihan praktis, observasi sistem, troubleshooting, dan dokumentasi.

## Lingkungan

- OS: Ubuntu
- Shell: Bash
- Virtualisasi: VirtualBox
- Lingkungan lab tambahan: Kali Linux

## Topik Pembelajaran

- Linux CLI
- Dasar-dasar Bash
- Filesystem
- Pengguna dan grup (Users and groups)
- Hak akses file (File permissions)
- Manajemen proses (Process management)
- Manajemen memori (Memory management)
- Disk dan filesystem
- Layanan (Services)
- Jaringan (Networking)
- Log sistem (System logs)
- Keamanan dasar Linux

## Tujuan

Membangun fondasi Linux yang kuat sebagai bagian dari persiapan saya
untuk berkarier di bidang Keamanan Siber (Cyber Security).

## Metodologi

Setiap topik mencakup:

1. Tujuan (Objective)
2. Lingkungan (Environment)
3. Perintah yang digunakan (Commands used)
4. Latihan praktis (Practical exercises)
5. Observasi (Observations)
6. Analisis (Analysis)
7. Pelajaran yang didapat (Lessons learned)
